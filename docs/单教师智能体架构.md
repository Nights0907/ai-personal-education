# 单教师智能体架构

日期：2026-11-08

## 原则

仅维护一个教师智能体：cmd/server的buildTeacher只创建一个agentic.Pipeline，一套teacher-system.md主提示词和一个teacher模型引用。不同能力通过模块注册Skill和Tool，模型读取目录、选择技能、执行工具并依据返回继续。数学复核、摘要与记忆提取使用辅助模型调用，不创建其他教师智能体。

四节点外壳负责预加载、运行时初始化、执行与输出；它不把教学步骤编码为业务流程节点。服务端按当前任务授权工具，智能体自主决定本轮如何使用。

## 入口与状态

网页解题、引导、复习统一POST /api/v1/agentic/chat。/solve保留旧客户端兼容，并调用同一个智能体。接口适配层区分解答回执流与对话消息流，不选择不同智能体。

学生选择、mode、当前题号GuideQuestionID与原始输入一起持久化。请求未携带模式/题号时服务端从会话记录恢复；引导初始题号从正式解答回执恢复。幂等重试保留原请求任务状态，不能变成后续任务。显式solve开启新解题任务。

防遗忘发题通过OpenReview显式保存review模式与原题号，不解析模型文本推断题号。服务端严格按学生隔离资源。

## 能力

- math-solve：读取题目、OCR、知识目录、解答校验、事务提交。新题只有正式回执才算成功。
- step-tutor：最小提示、逐轮提问；get_guide_outline读取结构，reveal_solution最终核对。绑定题目之外的工具请求会被拒绝。
- review-recall：get_review_question读取原题与参考答案；学生解释、教师对照检查；图片作答使用recognize_review_image。
- student-memory：读取档案与原始学习证据，辅助调整节奏。

终止工具只在本轮已授权时生效。对话轮次以合法教师回复结束，新题轮次以提交回执结束；这属于结果契约，不是独立智能体。

## 答案展示

引导首轮仍生成、校验、保存完整参考答案，对外不发送答案草稿、模型文字或正式解答。前端收到guide_start后，用同一智能体发起第一轮引导。参考解答的准备与逐轮教学是同一个智能体的不同任务轮次。

教师回复保存在Agent Store，网页恢复读取完整分页历史。Skill读取和工具执行结果不直接渲染成教师对话，防止暴露内部参考答案。

## 复习与记忆闭环

复习作答携带绑定原题的review状态，进入统一智能体而非新题求解。记忆读取端按绑定原题补齐知识点、难度与题号，保留本轮真实教师反馈，不用参考答案覆盖反馈。

原始问答封存后由后台提取，BuildMonth裁定并写入L2。只有提取结果包含有来源的学生实质作答，才把对应会话通知防遗忘模块标记REVIEWED。定时调度、幂等、存储和异步重试仍由服务端处理，不交给教师智能体自由决定。

## 兼容与边界

旧chat-system.md、guide-system.md不再用于服务启动。旧记录若已丢失mode/题号，不会自动补造。

参考答案是否展示仍有模型语义判断：完整推导与提示质量需持续评测；工具权限和数据归属由服务端检查。定时调度时区与首次到期发现是独立的已知问题，不属于本次单智能体收敛。
