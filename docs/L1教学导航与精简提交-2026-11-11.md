# L1教学导航与精简提交

L1新增navigation五类内容：learning_focus、observed_difficulties、support_needed、next_teaching_actions、evidence_refs。模型输入仅为已裁定L2，字段各最多3项、单项120字，引用检查当前学生月度L2路径、知识点和版本。由记忆后台worker生成，不在解题HTTP链路；L2与导航通过原有CAS一起发布。失败保留上一版导航并标stale，旧索引无导航时显示待生成。没有新增学生作答提取字段。保留原有索引关键词以兼容存储及查找，但动态上下文不再注入完整关键词清单，最多提供最近两份导航及L2路径。当前没有单独重算全部历史月份，随后台记忆更新生成。
