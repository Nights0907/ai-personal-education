# 功能全链路优化实现与验收

验收日期：2026-11-10。

## 架构

保持一个教师智能体，模型根据上下文选择技能及工具。解题、引导、学生作答核验、长期记忆读取均接入现有工具框架。作答核验与记忆抽取是受约束的模型能力调用，不是新增自治智能体。后台任务负责保存、重试、并发隔离、定时唤醒，不替代教师的教学决策。

## 已实现

- 引导式问答采用持久化异步任务：先发布不含答案的首问，再在后台生成、校验并正式保存解答；学生提前回答可排队，刷新可恢复，失败可重试。完成推导并经工具核验后才允许展示正式解答。
- 新题必须完成工具提交，不能把普通文本回复当作入库成功。识别公式明显断裂或矛盾时，提示核对文字，阻止错误题干进入正式解答。
- 记忆记录来源轮次、绑定题目、提示辅助情况、实际作答核验信息。提问与教师示范不计入掌握；缺少图片作答识别证据不更新掌握；未经核验不升级为已掌握。当前掌握与历史最佳分开，错误累计保留，旧画像标记待验证。
- 规范知识点标识、修复连续更新丢失、中文摘要长度、跨月继承与历史读取；摘要由已裁定的画像生成，避免自由摘要夸大学生能力。
- 记忆提交后的通知采用持久化事件，发送失败可重试。复习默认北京时间19点，支持当日配额、任务租约、防重复发送、历史学生自动建立监测计划、过期题目清理与再次到期的新周期。
- 提醒生成教师开场和可进入的会话；有效作答只完成对应题目的提醒周期。前端轮询站内提醒，支持历史任务恢复和会话删除后的防复活。

## 验证结果

- 全量 Go 测试：164 项通过，1 项可选真实模型测试跳过；实际 MySQL 与独立 Redis 参与集成测试。覆盖记忆存储、上下文读取、遗忘到期、提醒发送、作答回写、重复周期和中断恢复。
- 前端测试：20 项通过，1 项旧同步可选测试跳过；包含真实服务与真实模型的异步引导联调。采用 DOM 测试，未进行浏览器视觉验收。
- go vet 无报错。
- 真实模型文字题：请求即时受理，3.016 秒首问，32.297 秒参考解答保存完成；提前回答为 QUEUED，随后正确纠正间隔数错误；核验后展示解答；普通解题正式提交成功。
- 实际长期记忆读回：等差数列 current=partial、best=partial、assisted=true、total_errors=1；没有把引导完成误判为独立掌握。已自动建立 Asia/Shanghai、19点的监测计划。
- 实际图片识别返回损坏公式时：任务返回 needs_input，要求核对文字，没有发布引导首问或提交错误解答。

## 验收边界

上述耗时是样本记录，不是响应时间承诺。解题与作答评价仍依赖模型质量；OCR防护仅覆盖已识别的明显矛盾，不能保证所有识别错误均被发现。后台崩溃后通过租约回收，可能等待最多约4分钟。提醒目前为站内会话与页面轮询，没有新增手机离线推送。记忆保持度仍为启发式估算，没有宣称经过个体数据校准。旧历史事实保留但不追认独立掌握。
