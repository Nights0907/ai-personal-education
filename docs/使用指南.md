# 沐斯 AI · 数字人教师 —— 用户使用指南

> 一份面向使用者的完整指南：从「搜一道题」到「系统记住你、并在遗忘时提醒你复习」的全流程。

沐斯 AI 是一名专注高中数学的数字人教师。它不止会解题，更会**记住你的学习轨迹**，并在你快要忘记某个知识点时，**主动发题提醒你复习**——就像一位真正了解你的老师。

---

## 一、核心功能全景

整个系统围绕一个「学习闭环」运转：

```
搜题 → 模型解答 → 存入长期记忆 → 遗忘检测 → 防遗忘复习 → 回写记忆
```

| 阶段 | 功能             | 你能感知到的效果              |
| -- | -------------- | --------------------- |
| 搜题 | 文字输入 / 拍照上传    | 输入题干，或拍一张题照，系统自动识别    |
| 解答 | 大模型实时解答 + 校验入库 | 答案、解析、解题步骤，校验通过后才正式保存 |
| 记忆 | L0–L3 分层长期记忆   | 系统自动提取你的知识点、掌握度、犯错次数  |
| 遗忘 | 遗忘模型（可回忆概率 R）  | 每个知识点都有一个「还记得多少」的概率   |
| 复习 | 防遗忘计划 + 费曼检验   | 遗忘时自动发题，引导你重做原题、讲清思路  |
| 档案 | 个性化学习档案        | 一张图看懂你的掌握画像与待复习清单     |

## 二、快速上手（5 分钟）

### 第 1 步：打开系统

访问 `http://127.0.0.1:8080`，进入主界面。左侧是导航，中间是对话区，底部是输入框。

### 第 2 步：搜一道题

**方式 A：文字输入**  
在底部输入框直接输入题目，回车发送。例如：

> 求 f(x) = x² − 4x + 3 在 [0, 3] 上的最大值和最小值。

**方式 B：拍照上传**  
点击输入框旁的「上传」按钮，选择一张清晰的单题照片（JPG / PNG / WebP，≤5MB）。系统会自动 OCR 识别题目文字，再进行解答。

### 第 3 步：看解答

系统会实时显示解题过程：

- **答案**：最终结果
- **解析**：解题思路分析
- **解题步骤**：分步推导
- **知识点**：本题涉及的知识点标签

当显示「✓ 已正式入库」时，说明解答已通过校验并保存。

### 第 4 步：题目自动收录

解完的题目会自动进入「**我的题目**」抽屉（左上角入口），可随时回看、搜索。

## 三、特色功能详解

### 引导学习与后台任务

选择“引导学习”后，教师先围绕已知条件或目标提出一个起步问题，同时在后台生成、校验并保存完整参考解答，答案不会直接展示。

你可以先写思路；参考解答尚未准备好时，作答会先保存排队，准备完成后再继续反馈。刷新或关闭网页不会取消后台任务。失败时可使用“重试任务”，不用重新输入原题。服务进程异常中断后，任务会在租约到期后恢复；不是重启后立即重新执行。

只有学生补齐推导、最终核对通过，教师才会展示正式对照。提示后完成不等于已经能独立掌握。图片题需要先取得可靠的识别题干，起步问题才会开始。

### 1. 长期记忆（L0–L3 分层）

系统会在你解题后，自动从你的作答中提取学习信息，分层沉淀：

| 层级 | 内容    | 说明                  |
| -- | ----- | ------------------- |
| L0 | 基本信息  | 姓名、年级、学习目标、讲解偏好     |
| L1 | 记忆索引  | 每月关键词、对话轮次统计          |
| L2 | 知识点档案 | 每个知识点的当前掌握、提示依赖、近期错误和遗忘锚点 |
| L3 | 原始对话  | 你与老师的完整问答记录（留痕备查）   |

记忆在后台生成：完成引导核对或复习作答的轮次会优先处理，其他对话通常在 10 轮、新会话或两小时未回复时触发。只看教师答案不会自动认定掌握；提示后完成与独立答对会区分记录。旧版记录没有足够证据时显示“历史记录，待验证”。

### 2. 遗忘模型（可回忆概率 R）

系统用遗忘曲线模型（HLR）为每个知识点计算一个「**预计记忆保持度 R**」：

- R 越接近 1，说明你还记得很牢；
- R 跌破 **0.80** 阈值，即进入「遗忘边界」，系统会标记为「**待复习**」。

R 是基于稳定性、近期错误和间隔时间的启发式估计，不是经过校准的答对概率。R **不会写死**——你今天答对了，R 就上升；隔久了没复习，R 自然下降。

### 3. 防遗忘计划（随访式发题）

这是系统最「主动」的能力，类比医生的**随访计划**：

- 当你有知识点遗忘（R < 0.80），系统**自动为你建立防遗忘计划**（无需你确认）；
- **服务持续运行时，按上海时区每天最多发 1 道站内复习题**，优先发「最遗忘」的那道；
- 发过的题**自动去重**，不会重复轰炸；
- 你答完并掌握后，该题从待发清单移除；若答错，系统会继续跟进。

### 4. 费曼式复习检验

复习题不是简单地把答案甩给你，而是引导你**用费曼学习法**检验掌握：

> 系统会引导你「像给同学讲清楚一样，自述一遍解题思路」，或「动笔重新做一遍」，然后对照标准答案判定——答错了给最小提示，而不是直接给答案。

这样做的目的：**只提醒知识点是低效的「再认」，让你重做原题才是高效的「提取练习」**。

### 5. 个性化学习档案

点击左侧「**学习档案**」，进入你的专属档案页：

- **学生概览**：姓名、年级、学习目标、知识点数、待复习数、记忆月份数；
- **复习提醒**：列出所有「待复习」的知识点，标注可回忆概率；
- **掌握画像**：全部知识点按遗忘程度排序，每个知识点带掌握度徽章；
- **防遗忘计划**：查看每日发题数量、待发送 / 已发送 / 已复习计数；
- **题目链接**：每个知识点下方都有「产生它的题目」链接，点击可直接跳回那道题看完整解答。

## 四、典型使用场景

### 场景 1：日常刷题

每天打开系统，输入或拍照几道题，看解答、看解析、积累错题。系统在后台默默记住你的知识盲点。

### 场景 2：考前复习

打开「学习档案」，看「复习提醒」里哪些知识点已经遗忘，点击题号重新做一遍。系统会优先帮你巩固最薄弱、最久没碰的题。

### 场景 3：被动提分

你什么也不用做——系统在你遗忘知识点时，每天自动推一道复习题到你的对话里，用费曼法帮你「回锅」旧知识。

## 七、常见问题

**Q：为什么我的知识点显示「待复习」？**  
A：该知识点的可回忆概率 R 已跌破 0.80 阈值，说明距离上次学习已较久，系统建议你复习。

**Q：复习题会每天发吗？答错了会怎样？**  
A：每天最多发 1 道（可配置）。答错或之后再次到达复习窗口时，同题可以建立新的复习周期；仍受当天发题数量限制，不会连续轰炸。

**Q：拍照识别不准怎么办？**  
A：请上传清晰、完整、无需读图的单题照片。识别原文会展示给你核对；公式识别不完整时可改用文字输入。

**Q：我的数据安全吗？**  
A：系统只在本机运行（监听 127.0.0.1），主要业务记录存于本机 MySQL 与 Redis；解题、复核、记忆提取和OCR会调用配置的服务，相应题目、作答或必要背景可能发往服务提供方，并非全程离线。
